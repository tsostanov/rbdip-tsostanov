# Первая лабораторная

В `PricingCalculator` скидки и пороги вынесены в константы. Расчёт разбит на
небольшие методы: сумма позиций, скидка клиента, купон и скидка на крупный заказ.
Порядок расчёта и округление сохранены.

В `OrderService` осталось управление оформлением заказа. Проверка запроса,
подготовка товаров, сохранение и уведомление вынесены в отдельные классы.
Вместо двух списков с общими индексами используется список `PreparedOrderItem`.

Добавлены 21 проверка расчёта цены и 12 проверок оформления заказа.
Они прошли до и после рефакторинга. Эталонные тесты и схема БД не менялись.

Для первой лабораторной допускается до 15 замечаний суммарно. Сейчас их 8.

Полный `mvn verify` запускает 41 тест. Проходят 37, падают те же 4 проверки,
которые падали в исходном проекте: нормализация БД, миграции под нагрузкой,
N+1 и зависимости модуля отзывов. Это задания следующих лабораторных.
Maven продолжает сборку при падении тестов, поэтому результаты нужно смотреть
в `target/surefire-reports`, а не только по сообщению `BUILD SUCCESS`.

Только тесты первой лабораторной можно запустить так:

```powershell
mvn "-Dtest=OrderCreationTest,OrderApiReferenceTest,PricingCalculatorTest,PricingCalculatorReferenceTest" "-Dmaven.test.failure.ignore=false" test
```

Нужны Java 21 и работающий Docker. Перед сборкой на Windows нужно остановить
приложение, если оно запущено из `target/bookstore-0.1.0.jar`: файл может быть занят.
